# TimeTracker

**Куди пішов мій день?** TimeTracker тихо записує, яка програма у вас перед очима, і показує,
як час розподіляється між програмами за день, тиждень, місяць або весь час. Працює на Windows, офлайн, нічого не відправляє.

[English version](README.md)

## Можливості

- **Хронологія дня з окремою доріжкою для кожної програми.** Видно не лише підсумки, а й *коли* ви були в Blender, а коли в браузері. Наведіть на відрізок, щоб побачити точний час.
- **Тиждень, місяць і весь час.** Стовпчики по днях (або по місяцях для довгої історії); клік по стовпчику відкриває цей період. Окремий графік показує, о котрій годині ви зазвичай працюєте.
- **Чесні цифри.** Час без дій з клавіатурою чи мишею довше за поріг (типово 2 хв) не рахується. Екран блокування, сон і сам TimeTracker теж не рахуються.
- **Виключення.** Програму можна сховати одним кліком, і це можна скасувати. Вона зникає зі статистики, зокрема за минулі дні.
- **Живе в треї.** Закриття вікна не зупиняє облік. Пауза і продовження є в меню іконки. За бажанням програма запускається разом із Windows.
- **Експорт у CSV** по днях і програмах, з правильним кодуванням для Excel.
- **Автоматичні оновлення** з GitHub Releases. Їх можна вимкнути.
- Світла й темна теми.

## Завантаження

Завантажте `TimeTracker-windows-x64.zip` з [останнього релізу](../../releases/latest), розпакуйте будь-куди
й запустіть `TimeTracker.exe`. Це один файл, встановлювати .NET не потрібно.
Потрібна Windows 10/11 x64 (використовується Edge WebView2, який уже є у Windows).

Дані зберігаються в `%LOCALAPPDATA%\TimeTracker`: база `activity.db` (SQLite) і `settings.json`.

## Збірка

Відкрийте `TimeTracker.sln` у Visual Studio 2022 (.NET 9 SDK) і натисніть F5. Або з командного рядка:

```bash
dotnet build TimeTracker.sln
```

```bash
build.bat
```

`build.bat` збирає один файл `dist\TimeTracker.exe`. Перед збіркою закрийте запущену програму (трей → Вихід).

Інтерфейс можна правити без перезбірки. Згенеруйте попередній перегляд із тестовими даними й відкрийте його в браузері.
Параметри: `?theme=dark`, `?mode=month`, `?state=empty`, `?state=error`, `?paused=1`, `?update=ready`.

```bash
python tools/preview.py
```

## Випуск нової версії

1. Змініть `<Version>` у `src/TimeTracker/TimeTracker.csproj` і зробіть коміт.
2. Запуште тег із тією самою версією, наприклад `v2.2.0`.
3. [Workflow релізу](.github/workflows/release.yml) збере програму на GitHub Actions і прикріпить до релізу `TimeTracker-windows-x64.zip` та його `.sha256`.

Як працює вбудований оновлювач:
- раз на кілька годин перевіряє останній реліз;
- завантажує архів, звіряє SHA-256 і розпаковує в `%TEMP%`;
- коли програма закривається (або після «Перезапустити й оновити»), нова версія запускається звідти з `--apply-update`;
- вона чекає, поки старий процес завершиться, копіює себе поверх встановленого exe і запускається знову.

Якщо робите форк, змініть `Repo` у `src/TimeTracker/Core/AppInfo.cs`, щоб оновлення приходили з вашого репозиторію.
